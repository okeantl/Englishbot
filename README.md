# English Words Bot

Telegram-бот для ежедневного изучения английских слов: слова циклами, тексты для чтения с ИИ и произношение.

## Что умеет

- **Слова циклами.** В первый день 10 новых слов. Каждый следующий день пользователь повторяет все слова цикла и получает ещё 5: 10 → 15 → 20 → 25 → 30. Когда цикл набран, начинается новый, с другими словами. Выданное слово больше никогда не выдаётся как новое.
- **«Знаю это слово».** Знакомое слово убирается кнопкой, бот сразу выдаёт замену.
- **Тексты для чтения с ИИ.** LLM пишет короткий текст уровня B1 на случайную тему: читаешь, а непонятные слова отправляешь боту.
- **Произношение.** Любое английское слово, отправленное боту, возвращается с транскрипцией IPA, звучанием русскими буквами, переводом, примером и аудио (Free Dictionary API + LLM).
- **Проверка себя.** Квиз по словам цикла: перевод на выбор из 4 вариантов.
- **Напоминания** каждый день в выбранный час: `/remind 19`, `/remind off`.
- **Статистика:** пройденные слова, текущий цикл, серия дней подряд.
- **Админка:** `/admin`, пополнение словаря `/addwords`, рассылка `/broadcast`.

## Стек

Python 3.12, aiogram 3, SQLAlchemy 2.0 (async), PostgreSQL / SQLite, OpenAI SDK (бесплатные модели OpenRouter), Docker Compose, pytest, ruff, GitHub Actions.

## Запуск

```bash
cp .env.example .env      # вписать BOT_TOKEN и, по желанию, LLM_API_KEY
docker compose up -d --build
```

Локально без Docker (SQLite):

```bash
python -m venv .venv && .venv/Scripts/activate   # Linux/macOS: source .venv/bin/activate
pip install -r requirements-dev.txt
python -m bot
```

Тесты: `pytest -q`

## ИИ

По умолчанию используются бесплатные модели [OpenRouter](https://openrouter.ai): ключ создаётся на openrouter.ai/keys и указывается в `LLM_API_KEY`. Если основная модель недоступна, бот по очереди пробует запасные (`LLM_FALLBACK_MODELS`). Подойдёт любой OpenAI-совместимый API: достаточно поменять `LLM_BASE_URL` и `LLM_MODEL`. Без ключа слова, квиз и статистика работают, отключаются только тексты и ИИ-подсказки.

## Структура

```
bot/
  logic.py        правила циклов и серии дней (без БД, покрыто тестами)
  repo.py         работа с БД: выдача слов, квиз, статистика
  db.py           модели SQLAlchemy
  llm.py          тексты для чтения и подсказки по словам через LLM
  pronounce.py    транскрипция, аудио и перевод слова
  reminders.py    фоновая рассылка напоминаний
  handlers/       команды пользователя и администратора
data/words.json   словарь (~2900 слов и фразовых глаголов)
scripts/          пополнение словаря из файла
```
